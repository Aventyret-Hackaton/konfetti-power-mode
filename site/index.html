Konfetti.

A Chrome extension that turns every character you type on claude.ai into confetti. It piles up at the bottom of the screen for as long as you keep typing.

Download the latest zip

Always the newest version from GitHub. Not in the Chrome Web Store, so installing takes a minute.

Try it here

A small taste. The real thing runs in the prompt box on claude.ai.

What it does

  • Confetti per keystrokeEach typed character flies off with a burst of paper. Keep typing and the bursts grow.
  • A growing pileEverything lands at the bottom of the screen and stays there.
  • Blow it awaySwitch on the microphone and blow to clear the pile.
  • Super konfetti modeTyped text vanishes as it explodes, and Claude's answers appear in confetti.

Install

  1. Download the zip and unpack it. You get a folder called konfetti-plan-b. Put it somewhere it can stay, since Chrome loads the extension from that folder every time.
  2. In Chrome, open chrome://extensions (paste it into the address bar; web pages are not allowed to link to it).
  3. Turn on Developer mode in the top right corner.
  4. Click Load unpacked and select the konfetti-plan-b folder (the one that contains manifest.json).
  5. Open or reload a claude.ai tab and start typing.

Update

  1. Download the zip again and replace the contents of your konfetti-plan-b folder with the new one.
  2. On chrome://extensions, press the reload button on the Konfetti card.
  3. Reload your claude.ai tab.

Settings

  1. Blowing the pile away: click the Konfetti button in Chrome's toolbar (pin it from the puzzle-piece menu) and allow the microphone. The sound is only measured for loudness on the page and never recorded or sent anywhere.
  2. Super konfetti mode: right-click the Konfetti button, choose Options, and tick the box.
Runs only on claude.ai and makes no network requests. Source on GitHub.
